# 冷月系—Zlib知识库

AstrBot 4.29.4 的电子书工作流。入口：插件 → z-lib下载-导入知识库 → 书籍管理。

## 登录与搜索

点击“登录与设置 → 浏览器登录”，在真实官网页面中直接登录、完成网站要求的验证。窗口支持点击、键盘输入、粘贴、中文输入、滚动和拖动；网站弹出的登录页面会在同一窗口接续。插件自动取得并保存完整浏览器会话，不要求复制 Cookie、User-Agent 或账号凭据。

账号登录检查和真实图书搜索都成功后才显示“登录与搜索验证成功”。关闭登录窗口会保留会话；“退出登录”会清除插件的账号凭据与该站点的浏览器配置。插件不会替用户完成验证码。

搜索、接口请求和下载复用同一真实 Chromium 浏览器环境、浏览器 Cookie 与持久化配置，避免“账号接口登录成功但搜索被网站验证拦截”。会话在插件数据目录按站点隔离，管理页面不返回 Cookie。旧版已保存的账号会话可自动接续；仍需验证时直接打开登录窗口即可。

首次需要 Chromium 与 Linux 显示依赖。当前机器已经安装。其他部署中可点击“安装浏览器组件”；容器重建后如系统依赖丢失，可点击“修复浏览器组件”。安装来自 Playwright 官方运行时：Linux root 环境执行 `python -m playwright install --with-deps chromium`，浏览器二进制保存在持久化 plugin_data 下。其他环境先安装系统所需依赖。插件不另开监听端口，所有画面与输入通过 AstrBot 已认证的插件页面 API 传输。

## 下载、分析与导入

1. 核对自己使用的 HTTPS 站点及容器可访问的下载目录。默认使用本机现有 e-book 挂载目录；修改目录不会搬迁已有文件。
2. 搜索结果展示书名、作者、出版社、语言、年份、格式和大小；点击“详情”按需加载真实封面、ISBN、页数和简介。已打开过的封面可回显到对应结果卡片，不批量预取。缩略图仅在内存缓存，最多24张、30分钟过期，原图不另存文件。搜索、筛选格式，下载对应版本。格式来自真实搜索结果，不进行任意格式转换。下载完成后出现在本地书架。
3. 本地书架按“未导入 → 已导入”排列。点击文件，核对书名和版本，再分析正文。识别结果逐页持久保存；单页30秒未取得完整响应、返回错误或校验有争议时列入失败清单，后续页面继续处理。
4. 在“分析缓存与人工复核”打开缓存，查看失败页原图、原始模型回复和原因。可人工补录正文；确实无知识内容时直接点击跳过，原因选填。单页重试只在主动点击时调用模型，重试结果仍需人工确认。全部失败页处理完后勾选确认，生成章节、分块及过滤预览。明确匹配时预选知识库，歧义时由用户选择已有库或新建。点击“确认导入”才提交索引；关闭弹窗不入库。
5. 章节索引成功并校验数量后才标记已导入。新库的聊天授权仍在原生配置中管理，本插件不扩大原有权限。

PDF 无可靠书签时停止，可填写人工确认的物理页码章节表。EPUB 按目录与阅读顺序合并片段；TXT/MD 按标题或单一正文。MOBI/AZW3 等可下载，暂需转换后入库。

## 任务记录只读

任务记录只展示状态、章节、过滤报告和历史结果；记录弹窗没有分析、选库、新建或导入按钮。入库授权令牌不写入任务记录，也不随历史列表返回。0.4.0 的分析和人工审核保存在独立缓存，重载后从本地书架的“分析缓存与人工复核”接续；必须明确确认审核结果后才能生成入库预览。审核预览保存在受限缓存文件中，不再一小时自动失效。重新打开审核或删除缓存会使旧预览失效。

## 自动分块与质量

“分块软目标”原意是每块检索文本的大致长度，“重叠字符数”是相邻块复用的上下文长度。这两项不是普通用户必填设置，0.2.0 已从管理页面和插件配置表单移除，保留内部策略（默认1800/250，兼容已有配置值）。它们不决定章节边界。

扫描页先用所选视觉模型转录，再按章节合并。OCR 必须返回明确状态和实际正文；拒答、图片不支持、格式错误、截断、超时及疑似空白页都保存原始回复和失败原因，供人工审核，不能直接入库。未配置视觉模型时扫描页也进入人工复核，可以补录或配置模型后逐页重试。OCR 会产生模型调用；普通文本型 PDF 中的纯图片图表未单独识别，请核对重要图表。

缓存位于持久化插件数据目录 `analysis_cache/`。按源文件内容指纹、书名版本及目录复用页面结果；更换 OCR 模型不会自动重做已处理页，失败页也不会自动重试。关闭网页不停止后台处理；重载或重启会中断任务，但已落盘页面保留，点击“接续未处理页面”继续。缓存不自动过期，可在页面主动删除；删除不影响原文件和已入库文档。原图只在查看时从源文件按需渲染，不逐页重复保存图片。0.3.1及更早版本未落盘的识图正文无法恢复。

所有失败页必须补录或明确跳过，跳过原因选填；“上一页”可返回已处理页面查看或修改。重试成功也需人工确认。最后勾选“我已复核全部失败页”才生成入库预览；实际写库前再次检查已确认状态、OCR页码覆盖及全部分块。重新打开审核会撤销旧预览的授权；正在入库时不能修改或删除对应缓存。

物理分页不作为分块边界。按段落和句子组织正文，允许跨页，检索时补取同章相邻片段；完整章节通过 `chapter_knowledge_read` 分段读取。纯索引、目录、版权、前言、作者说明、参考文献等辅助章节先过滤，再清理重复页眉页脚，最后对分块作质量检查。短定义、解释性例子和带解释的公式不因短小被删除。过滤原因和样本可在分析预览及只读历史中查看。来源头（Book/Edition/Chapter/Leaf）不作为知识内容计分；分块生成后和实际写入前分别校验所有块，拒绝索引章节、空正文或超出章节边界的片段。统计样本表和短定义保留。

原文件不修改；既有 chapter_sources 映射与旧教材保持兼容，升级不会自动修改历史资料；这次按用户明确要求，已备份并重新导入迈尔斯《社会心理学》。其他书籍须用户在页面确认后才导入。

逐章调用原生 `KBHelper.upload_document(pre_chunked_text=...)`，复用原生嵌入与索引。部分失败回滚本任务新文档，保留旧资料；新建后入库失败可能留下空库，可在原生界面管理。

## 自然意图路由

标准 `@filter.command`、明确的 str/int 参数和默认值；管理指令保留 ADMIN 权限。刷新“自然意图与插件整合”即可发现并接入：

- 搜书(query, extension='', page=1)
- 下载书籍(book_id)
- 本地书架()
- 书籍入库预览(file_id, title='', edition='')
- 书库任务(job_id)
- 书库面板()
- 书籍章节(chapter='', book='', part=1)，只读且遵守会话知识库授权

最终审核和入库确认在管理页面的独立审核与导入弹窗提供。`chapter_knowledge_read` 工具名保留，兼容历史对话。

## 模块边界

- main.py：AstrBot 注册、权限与生命周期；web.py：认证后的管理 API。
- browser_session.py：真实浏览器、画面输入、会话持久化与浏览器下载，不独立开放端口。
- service.py：工作流，支持注入 provider_factory 和 extractor。
- providers/base.py：来源协议；providers/zlibrary.py：书籍元数据及下载校验，活动会话通过浏览器传输。
- ingestion/extract.py：解析、目录、页码与 OCR；ingestion/quality.py：清洗与分块；ingestion/ocr.py：OCR 响应校验；ingestion/review.py：逐页持久缓存、30秒超时、人工复核与审核状态。
- presentation.py：原站简介的段落与行内排版转为可读文本；
- covers.py：封面URL校验、限额缩略图及按需缓存；
- matching.py：可解释的知识库推荐；retrieval.py：完整章节和相邻检索。
- store.py：SQLite 任务台账及受限凭据文件；pages/library/review.js：独立人工审核页面控制；pages/library：原生 HTML/CSS/JS，无前端构建。

Cookie 和浏览器数据仅保存在插件数据目录，权限受限；不同站点隔离。浏览器校验证书，拦截真实私有网络目标，兼容本机代理的 198.18.0.0/16 Fake-IP 域名映射。下载流式处理或经浏览器下载通道，限制体积，校验格式，原子发布，不覆盖已有文件。

## 功能与本地配置分离

功能实现、兼容处理和界面改动直接维护在本插件仓库。账号绑定、权限白名单、Provider ID、Cookie、Token及其他私人配置保留在AstrBot本地配置或plugin_data，不纳入源码发布。升级功能源码时保留已有本地配置与数据。
